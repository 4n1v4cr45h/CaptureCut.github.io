ТЕХНИЧЕСКАЯ ЗАМЕТКА: CODE OSS НА KALI LINUX

Дата: 18.10.2026
Статус: Приложение запущено, ошибка проверки версии не устранена.

1. ЦЕЛЬ

Установить Code OSS на Kali Linux для дальнейшей работы с проектами и исследования веб-безопасности.

2. УСТАНОВКА

Выполнена команда:

sudo apt install code-oss git

Пакет code-oss успешно установлен из репозитория Kali Rolling.
Git уже был установлен.
Во время установки обновлены системные библиотеки и установлены необходимые зависимости.

Версия пакета Code OSS:
1.101.1+ds+really1.99.3-0kali1

3. ОБНАРУЖЕННАЯ ОШИБКА

При выполнении команды:

code-oss --version

Появилась ошибка:

Error: libnode.so.115: cannot open shared object file: No such file or directory

Также появилось предупреждение:

Warning: 'unity-launch' is not in the list of known options.

4. ФАКТИЧЕСКОЕ СОСТОЯНИЕ

Несмотря на ошибку команды проверки версии, графическое приложение Code OSS удалось запустить.

Работоспособность всех функций редактора и стабильность запуска дополнительно не проверялись.

Причина ошибки libnode.so.115 пока не установлена.

5. СОСТОЯНИЕ СИСТЕМЫ

- Kali Linux: используется.
- Code OSS: установлен, графический интерфейс запущен.
- Git: установлен.
- Burp Suite: работает, HTTP-запросы отображаются в Proxy -> HTTP history.
- SWR: исследование продолжается на основном компьютере.

6. СЛЕДУЮЩИЕ ДЕЙСТВИЯ

При необходимости проверить:

- стабильность запуска Code OSS;
- возможность создавать и редактировать файлы;
- причину ошибки libnode.so.115 при выполнении code-oss --version.

Не создавать вручную символические ссылки на несовместимые библиотеки и не устанавливать случайные библиотеки из сторонних источников.

ИТОГ

Code OSS установлен и графически запускается. Ошибка команды проверки версии остаётся неисследованной. Переустановка системы не требуется.
